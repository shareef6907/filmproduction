# Film Production Bahrain

Premium film production website for Bahrain Nights.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Add your assets to `/public`:
   - `header-video.mp4` - Your 10-second header video
   - `logo-white.png` - Your white logo
   - `poster.jpg` - Video poster/fallback image
   - `favicon.ico` - Website favicon
   - `apple-touch-icon.png` - Apple touch icon
   - `og-image.jpg` - Open Graph image (1200x630px)
   - `icon-192.png` - PWA icon 192x192
   - `icon-512.png` - PWA icon 512x512

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Deployment

Push to GitHub and Vercel will auto-deploy.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Vercel Hosting

## Performance Features

- Static Site Generation (SSG)
- Optimized images with next/image
- Lazy loading for videos
- Edge caching on Vercel
- Core Web Vitals optimized
